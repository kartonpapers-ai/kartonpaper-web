# Posavasos con personalidad

Cinco originales aportados por el dueño, conservados sin modificaciones, y dos heroes generados con IA a partir de ellos.

- Originales: San Pedro de Atacama, Bahía Inglesa, Desierto Florido y dos diseños de línea negra.
- Hero de escritorio: fotografía editorial con dibujos y espacio izquierdo para texto HTML.
- Hero móvil: composición vertical propia; también disponible para futuras campañas de redes.

Los títulos geográficos y dibujos forman parte de las imágenes. No hay slogan publicitario añadido a las composiciones. Dimensiones y pesos en catalogo.json.
