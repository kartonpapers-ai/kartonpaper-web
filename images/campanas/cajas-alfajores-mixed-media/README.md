# Cajas de alfajores · Mixed Media

Campaña generada con IA a partir de las referencias de cajas de cartulina blanca con visor de mica para 3, 4 y 6 alfajores. Fotografía de producto combinada con personajes de pastelería dibujados.

- `hero/cajas-alfajores-mixed-media-escritorio.webp`: composición panorámica; espacio izquierdo reservado para texto HTML y botones.
- `vertical/cajas-alfajores-mixed-media-vertical.webp`: composición vertical para redes y móvil.

Dimensiones y pesos reales en `../catalogo.json`. Sin texto publicitario integrado. Disponibles en el catálogo; no reemplazan el hero activo.
